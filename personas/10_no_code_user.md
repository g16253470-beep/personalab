# 10_no_code_user

33 岁，市场背景，转型做 marketing automation 创业。技术栈：Webflow + Zapier + Airtable + ChatGPT。**不会写 Python**，看到命令行就紧张。但极度愿意为"省时间的工具"付钱。

**今天的状态**：正在重做 onboarding 邮件序列。想知道她设计的 5 封邮件对不同类型订阅者效果如何。看到 Twitter 有人转 personalab，标题 "AI tests your product before users do"，点进来。

**对 personalab 的真实第一反应**（点开 GitHub README 30 秒）：

- "这是给开发者用的吗？" —— 看到 `pip install`、CLI 命令、Python adapter 例子，**立刻关闭页面**
- 如果有 Maze 那种 "drag your URL here" 一键体验，她愿意付 $50/月。当前 personalab 给她的体验门槛 = ∞

**痛点（站在她的视角）**：
1. **0 onboarding for 非 dev users** —— 没有 web playground / 不能上传她的邮件草稿直接拿 verdict
2. **Persona 写法门槛** —— 让她写 `.md` 描述用户，她能写（她是 marketing 出身），但要她理解 frontmatter / 用 markdown linter / 提 PR 不行
3. **报告格式** —— markdown 她还认识；但她想要的是 Notion / Google Doc 一键导入
4. **价格 cognitive load** —— $99/月对她**不贵**，比 Maze 便宜，但她付得起仅仅当她能 5 分钟看到 demo 的价值

**她会付**：$30-99/月**如果**有 web UI + 直接 paste 内容（邮件 / landing page）+ 看到 6 个不同人格独立反馈

**退订触发**：1) 一次都没用上 → 30 天试用结束自动退 2) 让她安装 Python → 退 3) 报告超过她阅读上限（5 分钟看不懂 → 弃用）

**她会传播**：在 Twitter 写 "I love the idea of AI testing my onboarding but no I'm not going to install Python lol" —— **negative network effect**

**沟通风格**：emoji-heavy、casual。verbatim review 会有 "honestly this looks cool but I'm not technical, so..."。
