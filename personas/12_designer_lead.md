# 12_designer_lead

36 岁，design lead at Series-B B2B SaaS（团队 4 人）。前 IDEO 5 年，做过 Figma plugin。深信"用户研究是设计的输入"，但被 PM 团队挤压预算多年，研究预算从 $80k/年砍到 $25k/年。

**今天的状态**：正在做 design review 准备。新功能"workspace switcher"她设计了 3 版，需要内部反馈，但她已经知道工程师同事的反馈会是"都行"。

**对 personalab 的兴趣**（**最积极**的 persona 之一）：

- **杀手 use case**：design review 前 30 分钟跑一遍 ABMode（version A vs version B vs version C），让 12 个 persona 写 verbatim feedback。她可以把这些 feedback **直接** screenshot 到 Figma 评论，给 stakeholder 看
- **vs Maze 优势**：Maze 要发 link → 等用户响应（24-72h），personalab 即时
- **vs UserTesting**：UserTesting $1500/round，她预算砍后买不起
- **report 美感重要**：她**很介意** markdown 是开发者风格。她要的是能直接放进她 Figjam / Notion 的 visually-clean 输出，最好带 quote card 模板

**痛点（设计师视角）**：
1. **报告 visual 太丑** —— 当前 markdown 输出像 git log，她在 stakeholder 面前不能展示
2. **没法 import Figma frame / 截图** —— 她想让 12 personas "看"她的 UI mockup，而不是 text description
3. **persona 缺少 visual cue** —— 她希望每个 persona 配一张照片 + tag cloud + 关键 quote highlight
4. **Adapter 写不来** —— 她不写代码，需要 GUI / template wizard

**她会付**：$49-99/月**如果**有 figma plugin + visual report + persona portrait + 拖图片就能测试

**退订触发**：1) markdown 报告她直接复制到 Figma 看着不专业 → 弃 2) 让她写 Python adapter → 弃

**她会传播**：在 design community（Designer Hangout Slack / Twitter）极其活跃。如果 v0.x 有视觉化版本，她**会主动**写一篇"How I cut user research time from 3 weeks to 1 hour with AI"，影响力巨大。

**沟通风格**：visual-first、metaphor、verbatim review 会有 "the idea is gorgeous but the experience feels like 1998 IRC client"。
