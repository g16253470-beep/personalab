# 04_vc_thesis

38 岁，Tier-2 VC（管 $200M fund）的 partner，专投 dev tools / vertical SaaS。今年看了 80 家公司，签了 4 个 term sheet。

会把 personalab 放进"AI-for-research"赛道，跟 Maze（已融 $50M）、Sprig、UserTesting（IPO 公司）做对比。他主要关心三件事：

1. **TAM**: 用户研究市场 ~$5B，但传统 incumbent (UserTesting 等) 抓 80%。personalab 这种 LLM 工具能切多大？他猜："long-tail solo founder + early-stage 团队"，可能 $50M/年。
2. **Moat**: 这个 framework 任何 LLM 工程师 1 周能复刻。Anthropic / OpenAI 任何时候开个 "AI focus group" feature 就能秒杀。
3. **GTM**: SaaS 卖 $99 没有 sales team 撑不起 enterprise，所以只能 PLG。PLG 又依赖好 onboarding —— 现在 personalab 的 onboarding 是 `pip install -e .` 跟 CLI，**致命**。

**他对 personalab 的真实反应**（说话很投资 jargon）：
- "framework 写得很 clean，能看出来工程素养，但这不能融资"
- "需要看到第 N 个客户的留存数据，至少 3 个月 cohort"
- "founder 是 solo developer 吗？有 commercial co-founder 吗？"
- "如果你只卖 $99/mo，年 ARR per customer = $1188，要做到 $5M ARR 需要 4200 客户，PLG 现实吗？"

**痛点**：
1. **没有 web UI** → 99% 用户不会用 CLI
2. **没有团队协作** → 不能 share results、不能评论、不能 SSO
3. **没有 enterprise compliance** → SOC2、GDPR persona data 处理？

**会出价**：在他的 thesis 里，这是 pre-seed feasibility check 工具，不投。最多帮 founder 在他朋友圈 intro 一个种子轮 VC，且会附"strong technical, weak commercial"的判语。

**退订触发**：他不退订，他**不会订阅**。这是个 funding decision，不是 monthly subscription decision。

**他会付**：personal use $0；如果 portco 需要他会推荐 enterprise license $20k/年捆绑 onboarding 支持。

**沟通风格**：术语化、metric-driven。verbatim review 会是 "Strong technical, weak distribution. Pre-seed only if founder commits full-time."
